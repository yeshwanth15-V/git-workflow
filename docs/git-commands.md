# Important Git Commands

## Repository Commands

| Command | Description |
|---|---|
| git init | Initialize a repository |
| git clone | Copy a remote repository |
| git status | Check repository status |
| git log | View commit history |

## Staging and Commit Commands

| Command | Description |
|---|---|
| git add . | Stage all changes |
| git commit -m "message" | Save changes |
| git diff | View file changes |
| git reset | Unstage changes |

## Branch Commands

| Command | Description |
|---|---|
| git branch | List branches |
| git switch branch | Switch branches |
| git switch -c branch | Create and switch branch |
| git merge branch | Merge another branch |

## Remote Commands

| Command | Description |
|---|---|
| git remote -v | View remote repositories |
| git fetch | Download remote updates |
| git pull | Fetch and integrate changes |
| git push | Upload commits |

## Stash Commands

| Command | Description |
|---|---|
| git stash | Temporarily save changes |
| git stash list | List saved stashes |
| git stash apply | Restore a stash |
| git stash pop | Restore and remove a stash |

## Tag Commands

| Command | Description |
|---|---|
| git tag | List tags |
| git tag v1.0 | Create a tag |
| git push origin v1.0 | Push a tag to GitHub |

## Conclusion

These commands help developers manage repositories, track changes, collaborate, and maintain project history.
