# Git Basics

## What is Git?

Git is a distributed version control system used to track changes in source code. It allows developers to collaborate, maintain project history, and manage different versions of a project.

## Important Git Concepts

### Repository
A repository stores project files and their version history.

### Commit
A commit is a snapshot of changes saved in Git history.

### Branch
A branch allows developers to work on different features independently without affecting the main codebase.

### Merge
Merge combines changes from different branches into a single branch.

### Pull Request
A Pull Request is a request to review and merge changes from one branch into another on GitHub.

### Git Tag
A tag marks a specific commit, commonly used to identify software releases.

### .gitignore
The `.gitignore` file specifies files and directories that Git should not track.
